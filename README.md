# Lipophilicity (logD) 预测模型

## 1. 任务简介

基于 MoleculeNet Lipophilicity 数据集，从分子 SMILES 预测 pH 7.4 下的辛醇/水分配系数对数值（logD，字段 `exp`），单任务回归。

本次完成了完整流水线：数据清洗 → 特征工程 → 四模型对比（岭回归、随机森林、GBR、GNN） → 骨架隔离评估 → 测试推理接口。

### 分析思路

**从易到难** 表格模型跑得快、可解释，几分钟就能发现数据坑（比如 `exp=999999` 哨兵值）。如果直接用 GNN，可能被异常值误导而不自知。跑通基线再上复杂模型。

**为什么 GBR 最优。** GBR 串行纠错——每棵新树只修前一棵的残差，天然抗过拟合。随机森林 200 棵树同时记训练集细节，训练 R²=0.93 但测试仅 0.58；GBR 训练 0.87 → 测试 0.62。

**为什么 GNN 没超过 GBR。** GBR 输入含 LogP，它本身就是 logD 的近似计算，占 26% 特征重要性。GNN 无此先验，从原子图自学到 R²=0.60，加入边特征后验证 R² 提升 10-15%。

**调参发现。** 对 RF 尝试三组参数，过强正则化（depth=10）反而降分，原始参数即最优——树模型的高训练/低测试差距不一定等于过拟合。

## 2. 数据集检查与预处理

原始数据存在以下问题，不可直接使用：

| 问题                                               | 数量 | 处理 |
| exp 列类型为 object（含字符串如 `.05`）              | -    | 强制转 float |
| 哨兵值 `exp=999999`（ID: `CHEMBL_BAD_EXP_EXTREME`） | 1    | 过滤 (abs>100) |
| 无效 SMILES（`not_a_smiles`、`C1(CC`）              | 2    | RDKit 解析过滤 |
| 缺失 exp 或 SMILES                                  | 3    | 丢弃 |
| 完全重复行                                          | 410  | 去重 |

清洗结果：4200 → **3784** 条，exp ∈ [-1.5, 4.5]，均值 2.18，标准差 1.20。

脚本：`data_cleaning.py` → `Lipophilicity_cleaned.csv`

## 3. 分子表示与输入处理

### 表格模型特征

| 类型         | 维度 | 说明 |
| 分子描述符    | 8    | MolWt, ExactMolWt, MolLogP, TPSA, HeavyAtomCount, NumRotatableBonds, RingCount, FractionCSP3 |
| Morgan 指纹 | 256   | 半径=2, 位长度=256 |
| **合计**    | **264** | |

全部在 CPU 完成，约 2 分钟 / 3784 个分子。Morgan 生成器全局复用一次初始化。

脚本：`feature_engineering.py` → `Lipophilicity_features.csv`

### GNN 分子图编码

纯 PyTorch 实现，零额外依赖。原子特征 24 维（元素类型+杂化+度+电荷/芳香性），边特征按键类型加权邻接矩阵（单键/双键/芳香键/三键）。网络：2层GCN → 全局平均池化 → MLP(64→32→1)。

脚本：`gnn_model.py`

## 4. Baseline 模型

训练了四个模型作为多级基线，70%/15%/15% 随机划分，RMSE 为主指标：

| 模型         | 类型        | 测试 RMSE | 测试 R²    | 用途             |
| **GBR**      | 梯度提升树  | **0.749** | **0.616** | 串行纠错，抗过拟合 |
| GNN (边特征) | 图神经网络   | 0.752     | 0.598     | 从原子图学习       |
| 随机森林     | 树集成      | 0.788      | 0.576     | 传统 ML 基线      |
| 岭回归       | 线性        | 0.906      | 0.439     | 性能地板          |

骨架隔离评估（仅 RF）：随机划分 RMSE=0.788 / 环骨架隔离 RMSE=0.909（+15.4%），模型保留了跨骨架泛化能力。

## 8. 实验结果与分析

### 四模型对比

| 模型         | RMSE       |  MAE    | R² |
| **GBR**      | **0.7492** | 0.5750 | **0.6161** |
| GNN (边特征) | 0.7524      | 0.5582 | 0.5983 |
| 随机森林     | 0.7876      | 0.5933 | 0.5757 |
| 岭回归       | 0.9056      | 0.7110 | 0.4390 |

### 泛化评估（仅 RF）

| 划分方式 | RMSE | R² |
| 随机划分 | 0.7876 | 0.5757 |
| 环骨架隔离 | 0.9092 | 0.3628 |

- GBR 最优，串行纠错有效提高泛化（训练/测试差距远小于 RF）
- GNN 在无 LogP 先验情况下逼近 GBR，加边特征后验证 R² 提升 10-15%
- 骨架隔离 RMSE 上升 15.4%，模型部分依赖相似分子，但仍有可迁移能力

### 待改进

| 方向                       |  说明                                           |
| GNN 边特征跑完完整训练      | 边特征已验证有效（val R²+10-15%），仅因CPU慢未跑完 |
| 真实 Murcko 骨架 split     | 当前用 RingCount+LogP 近似                       |
| 自动超参搜索 (GridSearchCV)| 当前仅手动试了3组RF参数，未做系统搜索              |
| GNN 加深 + 残差连接        | 当前仅2层GCN                                     |
| Morgan 位方差过滤          |  256位中大量近乎全零                              |
| 注意力池化                 | 当前为全局平均池化                                 |

## 9. 复现说明

```bash
conda env create -f env.yml
python data_cleaning.py         # 清洗 → Lipophilicity_cleaned.csv
python feature_engineering.py   # 特征 → Lipophilicity_features.csv

python predict.py [test.csv]    # 推理 → 报告 + test_predictions.csv
```

| 文件 | 功能 |
|------|------|
| `data_cleaning.py` | 4200→3784条，去无效/重复/异常 |
| `feature_engineering.py` | 8描述符+256 Morgan指纹 |
| `baseline_model.py` | RF+Ridge+GBR + 骨架隔离 |
| `gnn_model.py` | 纯 PyTorch GCN + 边特征 |
| `predict.py` | test.csv → 推理 → 评估报告 |
